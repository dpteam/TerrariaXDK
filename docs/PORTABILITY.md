# Переносимость

Что сделано, что осталось и почему это разделение такое, какое есть.

Короткая версия: **код больше не зависит от Windows там, где это ничего не стоит**, но
**сборка и запуск вне Windows пока невозможны**, и это не косметика, а отдельная работа
с другим уровнем риска. Ниже — точная граница.

---

## 1. Что уже платформонезависимо

| Место | Было | Стало |
|---|---|---|
| Аудит контента (`ContentAudit`) | сравнивал манифест с `\`, а листинг каталога отдаёт разделитель ОС | обе стороны нормализуются в `/` (`Portability.Portable` / `RelativeTo`) |
| Все пути к файлам | собраны `Path.Combine` — это и так было верно | осталось, но относительные имена проходят через `Portability.Native` |
| Флаг Collectors Edition | читал только реестр, вне Windows молча оставался `False` | настройка `[Game] CollectorsEdition` (Auto/True/False) + реестр только на Windows |
| `Main.cs` | `using Microsoft.Win32` в файле игровой логики | убран; реестр тронут в одном месте — `CollectorsEdition.IsActiveInRegistry`, за проверкой `Portability.IsWindows` |
| Платформа в логе | не было | `Platform : Windows (...), separator '\'` — первая строка после `Runtime` |

### Почему ошибка с разделителем была настоящей

```
манифест:      "Images/_sheetTiles"  →  приведено к "Images\_sheetTiles.xnb"
листинг (Win):  "Images\_sheetTiles.xnb"   →  совпало
листинг (Unix): "Images/_sheetTiles.xnb"   →  НЕ совпало
```

На Linux проверка «осиротевшие файлы», которая должна ловить мусор, объявила бы мусором все
277 МБ контента. Проверка, которая врёт всегда, хуже отсутствующей: к ней перестают
относиться серьёзно.

Теперь обе стороны приводятся к одному виду независимо, и это покрыто тестом
`portable paths` — он пишет настоящий каталог через файловую систему и проверяет, что
здоровое дерево даёт ноль замечаний, посторонний `.dds` — ровно одно, а манифест с
обратными слэшами (как было раньше) продолжает совпадать.

## 2. Что мешает сборке вне Windows

Это список препятствий, а не «потом посмотрим».

| Препятствие | Где | Что нужно |
|---|---|---|
| `TargetFramework=net40` | `TerrariaXDK.csproj` | multi-target на `net40` + `net8.0` (или Mono), и `.NET Framework` API, которых нет в Core |
| `UseWindowsForms=True`, `OutputType=WinExe` | csproj | `WinExe` → `Exe` для Unix; WinForms используется только для иконки/DPI — проверить |
| Нативные библиотеки `*.dll` | `tools/build.ps1`, `README` | на Linux — `libSDL2-2.0.so.0`, `libFNA3D.so`, `libFAudio.so`, `libtheorafile.so`; FNA грузит их по своим именам |
| Скрипт сборки — PowerShell | `tools/build.ps1` | отдельный `build.sh` (или `dotnet` + `make`) |
| Реестр | `CollectorsEdition` | уже обойдён: вне Windows просто не читается |
| `StorageDevice.RootOverride` | `AppPaths.EnsureDirectories` | в FNA это работает на всех платформах, но проверять нужно на месте |

**Почему это не сделано сейчас:** ни одну из этих правок нельзя проверить в этом окружении.
Нет ни Linux, ни OpenGL 2.1 (`NoSuitableGraphicsDeviceException`, `GDI Generic`), поэтому
«собрал под Linux» означало бы «написал и надеюсь». Правило проекта — не выдавать
непроверенное за работающее; см. `AGENTS.md`, раздел про обязательные проверки.

## 3. Что проверяемо и потому сделано

Всё из таблицы 1. Для каждой строки есть либо тест, либо видимая строка в логе:

- `portable paths` — конверсия путей в обе стороны, `RelativeTo` с разными разделителями,
  защита от ложного префикса (`Content` не должен отрезаться от `Contents`), реальный
  каталог с реальными файлами, манифест в двух написаниях, поведение флага CE;
- `content orphans` — гоняется на настоящем `Content/` (277 МБ) и на 30 файлах манифеста;
- `Platform :` в логе — видно, что игра о себе думает, в том числе когда что-то пошло не так
  на чужой машине.

## 4. Правило на будущее

> Путь, который **сравнивается** или **показывается**, должен быть переносимым (`/`).
> Путь, который **открывается**, должен быть нативным.

Обратный порядок — и получается проверка, которая проходит на машине автора и врёт на всех
остальных. Обе операции живут в `Terraria/Portability.cs`, чтобы не изобретать их заново:

```csharp
Portability.Portable("a\\b")              // "a/b"     — для сравнения и логов
Portability.Native("a/b")                 // "a\b"     — для File/Directory
Portability.Combine(root, "Images/a.xnb") // root + "Images\a.xnb"
Portability.RelativeTo(root, fullPath)    // "Images/a.xnb" — что бы ни вернул листинг
```
