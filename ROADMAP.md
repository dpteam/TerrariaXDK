# ROADMAP

Порядок работ по TerrariaXDK. Критерий готовности каждого пункта — «можно проверить»,
а не «написано». Идеи и обоснования — в `IDEAS.md`.

Легенда: `[x]` готово, `[~]` в работе, `[ ]` не начато.

---

## Этап 0 — База (готово)

- [x] Переименование TerrariaOGC → TerrariaXDK (сборка, exe, config, версия в меню).
- [x] Сборка одним `dotnet build`, net40/x64.
- [x] Git-репозиторий, `.gitignore`, автор `Terraria Agent`.

## Этап 3 — Мультиплеер без серверного EXE

- [x] `IPeerTransport` + `TcpPeer`: хост внутри процесса, фрейминг, handshake с версией
      протокола и подписью модов, roster, join/leave, relay, LAN-дискавери (UDP).
- [x] `NetworkSession` переведён на транспорт; локальные (split-screen) игроки
      замыкаются в процессе, удалённые идут по сети.
- [x] Подключение по адресу из `[Network] JoinAddress`.
- [x] Клиентское подключение: `NetworkSession.EndJoin` → `StartClientPeer` открывает TCP
      (раньше `EndJoin` не создавал транспорт вовсе — соединения не было).
- [x] Таймаут подключения (5 с), чтобы недоступный хост не вешал игру.
- [x] Отказоустойчивость: битый пакет от клиента не роняет хост/клиент (try/catch вокруг
      `CheckBytesServer`/`CheckBytesClient` и `Session.Update`).
- [x] Legacy Lidgren оставлен как fallback (`UseTcpTransport = false`).
- [x] Исправлен `AvailableNetworkSession`: свойства читали сами себя, из-за чего любой
      настоящий сервер в списке (LAN или из мастера) убивал процесс `StackOverflowException`.
- [x] Пароль хоста: проверяется до регистрации пира, клиенту приходит причина отказа.
- [x] Диагностика в игре: пинг (RTT), входящий/исходящий трафик, счётчики пакетов
      (`Terraria/Net/NetworkStats.cs`, показ в HUD при `NetMode != 0`).
- [x] Мастер-сервер: клиент публичного списка (`Terraria/Net/MasterServerClient.cs`)
      с HTTP/JSON-протоколом `GET /v1/servers`, `POST /v1/announce`, `POST /v1/remove`,
      кэшем в `Storage/Cache/servers.json`, таймаутом, backoff и жёсткой валидацией
      ответа. Публикация своего мира — `[Network] PublishToMaster` (по умолчанию off),
      объявления шлёт фоновый поток (`MasterPublisher`). Публичные серверы попадают
      в общий список вместе с LAN.
- [x] Свой минимальный JSON-парсер (`Terraria/Net/Json.cs`) — в net40 нет `System.Text.Json`.
- [x] Список серверов: LAN и мастер в одном месте, пометки `[pw]` (пароль) и
      `[mods]` (другая подпись модов, подключение всё равно откажет handshake),
      реальное число игроков/слотов.
- [ ] Экран списка серверов: карточки, пинг, обновление по кнопке и «избранное».
- [x] Прямое подключение по адресу: `D` или `Right Shoulder` на экране выбора мира
      открывает ввод `host[:port]`, разрешает имя и подключается. Работает и с
      виртуальной клавиатурой.
- [ ] Тест «два клиента + хост» в `--selftest` (сейчас проверяется только loopback).
- [ ] Dedicated-хост без окна (тот же транспорт, без `Main`).

## Этап 8 — Без нативных `.dll` (самый последний)

Цель: рядом с игрой не остаётся ни `SDL2.dll`, ни `FNA3D.dll`, ни `FAudio.dll`,
ни `libtheorafile.dll`. Кастомная FNA-сборка тянет зависимости сама, одинаково на
Windows и Linux/ARM. Обоснование, замеры и варианты — в `IDEAS.md`,
раздел «Полный отказ от нативных `.dll`».

Порядок — от дешёвого к дорогому:

- [ ] **8.1. Убрать `libtheorafile`.** Видео игра не использует
      (`Content.Load<Video>` не вызывается), библиотека нужна только `Video.cs`.
      Минус одна зависимость и 370 КБ.
- [ ] **8.2. Упаковать нативные либы в embedded resource** + распаковка в
      `Storage/Cache/native/` и загрузка по полному пути до первого P/Invoke.
      Работает на текущем net40, «рядом с exe чисто».
- [ ] **8.3. Слить FNA3D + FAudio + SDL2 в одну библиотеку** под Windows.
- [ ] **8.4. Повторить для Linux/ARM** (Anbernic): `.so`, `SONAME`, `rpath $ORIGIN`.
      Здесь статическая сборка особенно важна — на прошивках handheld'ов половины
      системных библиотек нет.
- [ ] **8.5. Полный static link / NativeAOT.** Требует миграции с net40 на
      современный .NET — отдельный большой проект, делать только после 8.1–8.4.

**DoD этапа:** папка с игрой состоит из exe, `Content/` и `Storage/` — и больше
ничего. Запускается на чистой Windows и на Anbernic без доустановки библиотек.

## Definition of Done

Пункт считается закрытым, когда одновременно:

1. `dotnet build` без ошибок;
2. `TerrariaXDK.exe --selftest` — 0 failed;
3. поведение описано в `README.md` или `docs/`;
4. изменение покрыто хотя бы одной проверкой в `Headless/SelfTest.cs`
   (если оно проверяемо без GPU);
5. коммит с осмысленным сообщением, автор — `Terraria Agent`.
